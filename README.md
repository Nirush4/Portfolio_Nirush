## Installation

### Prerequisites

Make sure you have **Node.js** (version 18 or above) and **npm** installed. Check your versions:

```bash
node -v
npm -v
```

### 1. Clone the repository

```bash
git clone https://github.com/Nirush4/Portfolio_Nirush.git
cd Portfolio_Nirush
```

### 2.npm install

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```
